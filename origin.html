Where it began / The origin post

The post that started Dux.

Spencer Hinson, in a Facebook post from August 13, 2023. It is reproduced here verbatim with the author’s permission, including the original spelling, capitals and punctuation, as the origin marker for Project Dux. The original post is public on Facebook: view the post on Facebook ↗.

A note on dates: the post describes AI tools as they were in August 2023. Model names, features, prices and context-window sizes have changed since. It is kept as a record of the thinking that began this project, not as a source of current facts. For current evidence, see the research library.

The post, verbatim

Spencer Hinson · August 13, 2023

Shared link: https://www.wbtv.com/.../08/10/pros-cons-using-ai-classroom/

The following is about a local news report on the coming advancements of AI tools like ChatGPT. Now while the story briefly touches on the topic of Generative AI, it leaves out a lot. Such as the various other LLMs(Large Language Model) already available that do much more than just generate text. For a quick example, Bard is now multimodal, meaning you can upload images and the model can recognize what is in the image. Since Bard can also run math and code, if that image contains an equation, Bard can solve it as well. I think you see where I am going with this. Now I do believe PROPER use of these tools in education will be a great boon, and… inevitable. There needs to be discussion around this because it will happen faster than you think and it already is. As I have stated before regarding AI; The need for proactivity in AI regulation is an understatement. With AI, acting retroactively if something happens may not even be possible.

So let’s go over what else is out there other than ChatGPT.(Which to be honest is kinda old news, and definitely will be before “next fall”. There will be so much more before then that ChatGPT may be an old backup model and that’s it. AI advancement is exponential.)

I want to include a lot so here we go. Starting at the top we have ChatGPT’s predecessor. For those who don’t know, ChatGPT utilizes a model known as GPT-3.5 Turbo to produce its outputs. In fact, all ChatGPT is, is an interface to interact with the model in a conversational “assistant” like manner. If you listen to talks about interacting with the base models of GPT-4 and such, this assistant/user prompting will make more sense. Now you have other models, such as GPT-4. Which(with the plugin and code interpreter modes) is still the most effective model. All around a beast but definitely the best coding model out there. The tasks it can complete are pretty amazing to see. Now I’m not saying it’s the best for writing code, GitHub CoPilot and other AI tools are obviously better and more convenient. But as an LLM just given a coding task, GPT-4 is hard to beat right now. And the development of open-source applications utilizing these model’s APIs such as Auto-GPT and BabyAGI are only fueling the upcoming risks of what a more capable model could accomplish given the same abilities. Now, the use of GPT-4 is not free(on OpenAI’s website 😏), so I suspect not everyone will have access to it. But there are a variety of other LLMs and tools that are, such as Bard. Which is not only free(for now), rather capable as it is powered by Google’s PaLM-2 model(but still prone to A LOT of ‘hallucinations’), it is capable of up to 40 languages and as I said before, multimodal. So the effectiveness of what Bard can do is rather significant, not to mention the convenient features of automatically exporting code to Colab or Replit, entire responses to Docs, and the new TTS feature. All very nice. Now another quite capable model that has recently been made available that is worth mentioning I would say is Claude 2. It has the effective capabilities of a model close to ChatGPT and GPT-4, WITH the TREMENDOUS gain of a 100k Token Context window. In other words, Claude can read and retain around 75,000 words of context to use for your chats. I cannot understate how much bigger and bigger context windows will be such a game changer. Now I don’t want to get too much into speculation, but it is suspected Google’s upcoming multimodal LLM Gemini could have a context window of up to 1M Tokens. I think they will try their hardest to make it as large as possible and I hope so. Also looking forward to the “Gecko” version of PaLM-2’s model, that will be very cool. Alright, back to the top tools and why I think all of this is important. Because while the majority of the population may be unaware of these technologies, your kids may not be. And with the current state of these technologies and tools, I would advise EVERYONE educate themselves on all of this and more. There will need to be regulations in schools and parental guidance to fight all these tools so that kids don’t abuse them. So the flesh and blood kids still learn something. AI might be a great tool for us in the future… but over-reliance on it seems like a terrifying prospect and a recipe for disaster.

Now, there is so much more to mention… Such as the current issue of “hallucinations”, what they are, which models are more prone to it, how they could actually cause incorrect information to come about if the material is spread, etc. These are also just mainly the text AI LLM tools. Models are generating human-like text, decent bits of code, art, music and bits of video. There are increasingly capable open-source models being developed and released, which are really good. The Transformer architecture itself and the emergent capabilities of extremely large LLMs. We have things like Google’s Deepmind working on protein folding and med-PaLM. Their robotics lab with things like RT-2(look into it, it’s cool) and just so much more. So I hope just a little of all this I mentioned here, brings attention and awareness to the topic as you all head into the next school year… and the most interesting time for humanity there will ever be.
