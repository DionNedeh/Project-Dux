# Project Dux research library

Research snapshot: 12 November 2026. This library examines learning about AI, learning with AI, learning without it, and conditions for safe and equitable education. The corpus is a starting foundation, not an exhaustive or systematic review. Read source notes for design, access and limits; policy guidance is not trial evidence. Findings from particular populations, models and tasks should not be generalized to every learner.
